## 安装

```bash
npm i @muyianking/hooks
```

```bash
yarn add @muyianking/hooks
```

```bash
pnpm i @muyianking/hooks
```

## 文档

完整文档见 [docs](https://github.com/MuyianKing/hooks/blob/main/docs/README.md)。

| Hook                   | 说明                                                | 文档                                                                                                   |
| ---------------------- | --------------------------------------------------- | ------------------------------------------------------------------------------------------------------ |
| useAutoHeightAnimation | 使高度自适应的区域也能拥有展开收起的动画            | [useAutoHeightAnimation](https://github.com/MuyianKing/hooks/blob/main/docs/useAutoHeightAnimation.md) |
| useList                | 列表页逻辑：查询条件、分页、防抖搜索、更新单行      | [useList](https://github.com/MuyianKing/hooks/blob/main/docs/useList.md)                               |
| useListRequest         | 分页列表查询：loading、列表数据、数据累加、自动序号 | [useListRequest](https://github.com/MuyianKing/hooks/blob/main/docs/useListRequest.md)                 |
| usePageRequest         | 页面查询：查询条件、响应式数据、挂载后自动执行      | [usePageRequest](https://github.com/MuyianKing/hooks/blob/main/docs/usePageRequest.md)                 |
| useRequest             | 普通请求：手动触发、loading 状态                    | [useRequest](https://github.com/MuyianKing/hooks/blob/main/docs/useRequest.md)                         |
